# Installation Web PokeTama Moretro3D

Cette page est publiee automatiquement par GitHub Pages depuis le depot Moretro3D/Test-1.

Elle permet :

- d'installer le firmware Moretro3D avec Chrome ou Edge ;
- de conserver la sauvegarde pendant une mise a jour ;
- d'installer automatiquement les sprites, decors et musiques sur la microSD ;
- de reparer uniquement les trois musiques si le reste de la carte est deja installe.

Le dossier `firmware` est genere automatiquement par l'action GitHub. `sprites.pak` et `music.pak` contiennent les fichiers destines a la microSD.

Projet gratuit et non commercial.
