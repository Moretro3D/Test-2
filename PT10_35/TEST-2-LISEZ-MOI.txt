POKETAMA TEST-2 - VERSION NORMALE COMPLETE 386 POKEMON

VERSION INTERNE : 1.46.114 / V10.35 (sprites du popup Boite corriges)

Cette version conserve l'interface et le fonctionnement normaux. Les sprites
des 386 Pokémon restent installés, mais la Boîte n'ouvre plus artificiellement
toutes les espèces. Les vrais Pokémon obtenus et la sauvegarde sont conservés.
Il n'existe plus de boutons spéciaux JOUEUR/ADVERSAIRE.

IMPORTANT : sur un appareil ayant utilisé l'ancien mode Test-2, un Pokémon
sélectionné pendant ce test peut déjà avoir un profil enregistré. Sans marqueur
d'origine dans l'ancienne sauvegarde, il n'est pas possible de le supprimer
automatiquement sans risquer de retirer un Pokémon réellement obtenu.

Les 386 formes normales et les 386 formes Shiny sont présentes dans ce dossier,
ainsi que les fonds, les musiques et le pack web. Le premier déploiement Test-2
peut reconstruire le pack à partir de ces fichiers.

ÉVOLUTIONS AUTOMATIQUES
- Toutes les évolutions inscrites dans le Pokédex utilisent désormais un niveau.
- Aucune pierre, échange ou condition spéciale n'est nécessaire dans ce test.
- L'animation se lance automatiquement à chaque étape, même pour un Pokémon
  qui avait déjà dépassé le niveau requis avant la mise à jour.
- Exemple : Pichu niveau 100 devient Pikachu puis Raichu, en deux animations.
- Le Pokémon obtenu remplace sa forme précédente dans la Boîte.
- Évoli suit la branche actuellement inscrite dans la table : Aquali.

NOUVEAU SYSTÈME DE TAILLE
- Toutes les anciennes corrections et le prorata Pokédex sont désactivés.
- Les 386 Pokémon repartent à 100 % pour réaliser un contrôle propre.
- Chaque Pokémon possède une seule taille finale utilisée sur l'écran principal,
  la fiche générale, le côté joueur et le côté adversaire du combat.
- Les positions peuvent rester différentes par page sans modifier cette taille.
- La configuration se trouve dans battle_sprite_layout.h.
- Kyogre (#382) : 130 % sur l'accueil, la fiche et le combat.
- Tyranocif (#248) : 130 % sur l'accueil, la fiche et le combat.
- Artikodin (#144), Électhor (#145) et Sulfura (#146) : 130 % également.
- Chaque Pokémon utilise maintenant une des sept plateformes de combat selon
  ses types : Plante, Eau, Feu, Normal, Roche, Glace ou Nuages.
- Les doubles types gardent d'abord leur décor élémentaire ; Vol utilise les
  nuages quand aucun décor élémentaire plus précis ne s'applique.

1. Cree sur GitHub un depot PUBLIC et VIDE nomme Test-2
   (sans README, licence ni .gitignore). Tu pourras le supprimer apres le test.
2. Lance ENVOYER_TEST_2.bat et connecte-toi a GitHub si Windows le demande.
3. Ouvre l'onglet Actions et laisse finir
   « PokeTama Test-2 - Page installateur temporaire ».
4. Dans Settings > Pages, verifie que Source est regle sur GitHub Actions.
5. Ouvre https://moretro3d.github.io/Test-2/
6. Branche le PokeTama et clique sur Installer le firmware Moretro3D.
7. Choisis sans effacement pour conserver ta sauvegarde.

SECURITE
- Cette variante publie volontairement une page GitHub Pages temporaire.
- Supprime le depot Test-2 apres ton essai pour supprimer la page.
- Test-1 et Shopify ne sont jamais modifies.
- L'artefact est conserve 30 jours.
