POKETAMA TEST-2 - VERSION NORMALE COMPLETE 386 POKEMON

VERSION INTERNE : 1.46.61 (nouveaux noms de binaires pour éviter le cache)

Cette version conserve l'interface et le fonctionnement normaux. Les 386 Pokémon
sont disponibles dans la Boîte afin de pouvoir les sélectionner et les contrôler.
Il n'existe plus de boutons spéciaux JOUEUR/ADVERSAIRE.

Les 386 formes normales et les 386 formes Shiny sont retéléchargées depuis les
sources originales PMD SpriteCollab lors du premier déploiement Test-2.

NOUVEAU SYSTÈME DE TAILLE
- Toutes les anciennes corrections et le prorata Pokédex sont désactivés.
- Les 386 Pokémon repartent à 100 % pour réaliser un contrôle propre.
- Chaque Pokémon possède une seule taille finale utilisée sur l'écran principal,
  la fiche générale, le côté joueur et le côté adversaire du combat.
- Les positions peuvent rester différentes par page sans modifier cette taille.
- La configuration se trouve dans battle_sprite_layout.h.

1. Cree sur GitHub un depot PUBLIC et VIDE nomme Test-2
   (sans README, licence ni .gitignore). Tu pourras le supprimer apres le test.
2. Lance ENVOYER_TEST_2.bat et connecte-toi a GitHub si Windows le demande.
3. Ouvre l'onglet Actions et laisse finir
   « PokeTama Test-2 - Page installateur temporaire ».
4. Dans Settings > Pages, verifie que Source est regle sur GitHub Actions.
5. Ouvre https://moretro3d.github.io/Test-2/
6. Branche le PokeTama et clique sur Installer le firmware Moretro3D.
7. Choisis sans effacement pour conserver ta sauvegarde.

SECURITE
- Cette variante publie volontairement une page GitHub Pages temporaire.
- Supprime le depot Test-2 apres ton essai pour supprimer la page.
- Test-1 et Shopify ne sont jamais modifies.
- L'artefact est conserve 30 jours.
