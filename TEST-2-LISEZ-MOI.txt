POKETAMA TEST-2 - VERSION SPECIALE AUDIT DES 386 SPRITES

MODE D'EMPLOI
1. Ouvre la Boîte : les 386 Pokémon sont visibles virtuellement.
2. Touche un Pokémon pour ouvrir sa fiche.
3. JOUEUR le charge comme compagnon pour contrôler son sprite côté joueur.
4. ADVERSAIRE lance immédiatement un combat contre lui pour contrôler son sprite sauvage.

Cette version est uniquement destinée aux tests. Le déverrouillage des 386 Pokémon
est virtuel et ne remplit pas les bits de capture de la sauvegarde normale.

CORRECTIONS DE TAILLE EN COURS
- Latios : +30 %
- Première liste utilisateur de 36 Pokémon : +10 %
- Pichu et Togepi : -10 %
- Les corrections s'appliquent au joueur et à l'adversaire.
- Un prorata automatique basé sur la hauteur Pokédex est appliqué aux 386 espèces.
- L'échelle est comprimée entre 84 % et 116 % pour rester lisible sur 1,75 pouce.

1. Cree sur GitHub un depot PUBLIC et VIDE nomme Test-2
   (sans README, licence ni .gitignore). Tu pourras le supprimer apres le test.
2. Lance ENVOYER_TEST_2.bat et connecte-toi a GitHub si Windows le demande.
3. Ouvre l'onglet Actions et laisse finir
   « PokeTama Test-2 - Page installateur temporaire ».
4. Dans Settings > Pages, verifie que Source est regle sur GitHub Actions.
5. Ouvre https://moretro3d.github.io/Test-2/
6. Branche le PokeTama et clique sur Installer le firmware Moretro3D.
7. Choisis sans effacement pour conserver ta sauvegarde.

SECURITE
- Cette variante publie volontairement une page GitHub Pages temporaire.
- Supprime le depot Test-2 apres ton essai pour supprimer la page.
- Test-1 et Shopify ne sont jamais modifies.
- L'artefact est conserve 30 jours.
